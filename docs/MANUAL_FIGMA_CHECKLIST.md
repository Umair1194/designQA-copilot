# Manual Figma test file checklist

- Selection containing failing and passing solid text contrast
- Empty/default-named/hidden/deeply nested layers
- Responsive mobile, tablet, and desktop family
- Button/input component sets with complete and missing states
- Long English, pseudo-localized, and RTL text
- Form errors, loading, empty, offline, success, and destructive confirmation states
- Chart using color plus labels/patterns
- Multi-page file large enough to observe progress and cancel
- Navigate to each issue, preview a fix, export JSON/CSV/HTML, save baseline, rescan
